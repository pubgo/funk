# v2.0.5 Release Notes

**Date:** 2026-06-25  
**Tag:** [v2.0.5](https://github.com/pubgo/funk/releases/tag/v2.0.5)

```bash
go get github.com/pubgo/funk/v2@v2.0.5
```

## Highlights

This release focuses on **errors ergonomics**: richer tag helpers, readable error chains, safer JSON serialization, and tighter integration with `log` and `result`.

### errors

| API | Purpose |
|-----|---------|
| `GetTags` / `CollectTags` / `CollectUserTags` | Read metadata from the error chain |
| `FormatChain` / `FullMessage` | Human-readable joined messages for logs and UI |
| `MarshalError` | JSON marshal without panicking |
| `Walk` / `RootCause` | Traverse or resolve the deepest error |

**Behavior changes (non-breaking):**

- `Wrap` / `Wrapf` still preserve root `Error()` text; use `FormatChain` when you need the full story
- `WrapStack` no longer prints stacks to stderr
- `JsonPrint` returns `nil` on marshal failure instead of panicking
- `ErrJsonify` now expands the full unwrap chain

See [errors/README.md](../../errors/README.md) and [errors/errcode/README.md](../../errors/errcode/README.md).

### log

`log.Err(err)` now automatically adds:

- `error_id`
- `error_chain`
- `error_tags`
- `error_detail`

### result

```go
r := result.ErrOf(err)
r.Message() // full formatted chain
r.Tags()    // user tags without wrap-layer "msg"
```

### errcode

- `RegisterErrCode` — returns an error on duplicates
- `MustRegisterErrCode` — panic-on-failure helper for `init()`
- `LookupErrCode(name)` — fetch a registered code by name

## Upgrade notes

No breaking API removals. If you relied on:

- `JsonPrint` panicking on marshal errors — check for `nil` return or switch to `MarshalError`
- `WrapStack` writing to stderr — use `DebugPrint` or `String()` when you need visible stack output
- `NewCodeErrWithMsg` title-casing messages — messages now keep caller casing (`TrimSpace` only)
