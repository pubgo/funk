# v2.1.0 Release Notes

**Date:** 2026-11-14  
**Tag:** [v2.1.0](https://github.com/pubgo/funk/releases/tag/v2.1.0)

```bash
go get github.com/pubgo/funk/v2@v2.1.0
```

## Highlights

This release removes three external dependencies (`a8m/envsubst`, `ettle/strcase`, `iancoleman/strcase` — the latter two vendored/ replaced with `internal/strcase`), fixes two long-standing environment substitution bugs, hardens the `env` package's key resolution, and adds glob-based logger suppression plus a coverage gate.

## Upgrade notes (behavior changes)

1. **`${VAR:default}` now applies defaults.** Previously the envsubst-based substitution treated the single-colon form as a bash substring offset, so `${PORT:8080}` resolved to empty when `PORT` was unset. It now resolves to `8080`. Bash-specific operators (`${VAR-word}` without colon, `:=`, `:+`, nested defaults, substring offsets) are no longer supported — use `${VAR:default}` or `${VAR:-default}`.
2. **Key resolution is raw-name-first with normalized fallbacks.** `env.Get`/`Lookup`/`Expand` try the raw key, then the normalized key (`T2HOST` → `T2_HOST`), then the normalized uppercase key. Only affects processes holding the same key in two spellings with different values.
3. **Regenerating proto error codes changes registered identity strings** for names with digits or acronym boundaries (`sha_256_mismatch` → `sha256_mismatch`, `ApikeyErrCode` → `ApiKeyErrCode`). Update any log/monitor/routing logic that matches the old strings.
4. **Dropped dependencies**: `github.com/a8m/envsubst`, `github.com/ettle/strcase` (vendored as `internal/strcase`, MIT preserved), `github.com/iancoleman/strcase`.

## Added

### env

| API | Purpose |
|-----|---------|
| `GetBoolOr` / `GetIntOr` / `GetFloatOr` | Typed getters with explicit defaults on unset/empty/parse-error |
| `MustLoadFiles` | Panicking variant of `LoadFiles` |
| `Expand` | `${NAME}`, `${NAME:default}`, `${NAME:-default}` substitution (replaces envsubst) |

### log

| API | Purpose |
|-----|---------|
| `SetDisabledLoggers` | Glob-based logger suppression; bare patterns include their whole subtree |
| `IsDisabled` / `IsDisabledEvent` | Query/compose the disabled list from custom checkers |

### CI / tooling

- `.testcoverage.yml` coverage gate (vladopajic/go-test-coverage) wired into CI
- Docs site publishing via pubgo/markview: <https://pubgo.github.io/funk/>
- `.agents/` directory for team-shared agent assets (skills, commands)

## Changed

- `env` key resolution: raw name first, then `keyHandler`-normalized, then normalized uppercase — keys containing digits resolve regardless of case
- `env.Delete` unsets every stored spelling of a key
- `log`: hooks and checkers see the component name through the context field map; `env` follows the current `slog.Default()` instead of caching it
- `component/resty`: dropped deprecated `net.Dialer.DualStack`

## Fixed

- `${VAR:default}` silently resolving to empty (numeric defaults like `${PORT:8080}` never applied)
- Keys containing digits failing to resolve (`T2HOST` stored as `T2_HOST` was unreachable by its raw name)
- `component/resty` staticcheck SA1019 lint failure
