# v2.0.5 发布说明

**日期：** 2026-06-25  
**标签：** [v2.0.5](https://github.com/pubgo/funk/releases/tag/v2.0.5)

```bash
go get github.com/pubgo/funk/v2@v2.0.5
```

## 亮点

本版本聚焦 **errors 易用性**：更丰富的 tags 辅助函数、可读错误链、更安全的 JSON 序列化，以及与 `log`、`result` 的深度集成。

### errors

| API | 用途 |
|-----|------|
| `GetTags` / `CollectTags` / `CollectUserTags` | 从错误链读取元数据 |
| `FormatChain` / `FullMessage` | 拼接适合日志/UI 的可读消息 |
| `MarshalError` | 不 panic 的 JSON 序列化 |
| `Walk` / `RootCause` | 遍历或获取最底层错误 |

**行为变化（非破坏性）：**

- `Wrap` / `Wrapf` 仍保留根 `Error()` 文本；需要完整上下文时用 `FormatChain`
- `WrapStack` 不再向 stderr 打印栈
- `JsonPrint` 序列化失败时返回 `nil` 而非 panic
- `ErrJsonify` 会展开完整 unwrap 链

详见 [errors/README.md](../../errors/README.md) 与 [errors/errcode/README.md](../../errors/errcode/README.md)。

### log

`log.Err(err)` 现在自动附加：

- `error_id`
- `error_chain`
- `error_tags`
- `error_detail`

### result

```go
r := result.ErrOf(err)
r.Message() // 完整格式化错误链
r.Tags()    // 用户 tags（不含包装层 msg）
```

### errcode

- `RegisterErrCode` — 重复注册返回 error
- `MustRegisterErrCode` — 供 `init()` 使用的 panic 版
- `LookupErrCode(name)` — 按名称查找已注册错误码

## 升级说明

无 API 删除。若你依赖了以下行为，请注意：

- `JsonPrint` 在 marshal 失败时 panic → 请检查 `nil` 或改用 `MarshalError`
- `WrapStack` 写 stderr → 需要可见栈时用 `DebugPrint` 或 `String()`
- `NewCodeErrWithMsg` 自动大写 → 现在仅 `TrimSpace`，保留调用方大小写

完整迁移示例见 [UPGRADE-v2.0.4-to-v2.0.5.md](./UPGRADE-v2.0.4-to-v2.0.5.md)。
